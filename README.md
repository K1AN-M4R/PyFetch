PyFetch

A lightweight, cross-platform system information tool written in Python.

PyFetch displays useful information about your computer directly in the terminal, with a simple interface and no external Python dependencies.

✨ Features

- 🖥️ CPU Information
- 🧠 RAM Usage
- 💾 System Information
- 🐧 Linux Support
- 🪟 Windows Support
- ⚡ Lightweight and Fast
- 📦 No External Dependencies

🛠️ Requirements

- Python 3.8 or newer
- Linux or Windows
- No external Python packages required

🚀 Installation

Clone the repository:

git clone https://github.com/K1AN-M4R/PyFetch.git

Enter the project directory:

cd PyFetch

Run PyFetch:

python pyfetch.py

🧰 Built With

- Python
- Python Standard Library

🎯 Project Goals

PyFetch aims to provide a simple, lightweight, and dependency-free way to inspect system information through the command line.
